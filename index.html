Cómo trabajamos hoy

  • Trabajás con tu compañero/a de banco, como están sentados, y comparten una compu.
  • Cada ejercicio va con lo que se está haciendo en el pizarrón. Cuando el profe anuncia un bloque nuevo, pasan al ejercicio con ese número.
  • Primero se dibuja, después se programa. Los puntos EN PAPEL se resuelven en una hoja con los nombres de los dos, y los EN LA COMPU sirven para comprobar.
  • Si a uno de los dos lo llaman al pizarrón, el otro sigue trabajando. Cuando vuelve, se ponen al día y continúan juntos. Los DESAFÍOS ★ son para quienes terminan antes.
  • Al final de la clase entregan la hoja con todo lo resuelto.

Código base para la compu

Copienlo al principio de su archivo: tiene los moldes y las funciones que ya vimos en la Misión Expo.

class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

class NodoArbol:
    def __init__(self, dato):
        self.dato = dato
        self.izq = None
        self.der = None

def mostrar(cabeza):
    actual = cabeza
    while actual is not None:
        print(actual.dato)
        actual = actual.siguiente

def agregar_al_inicio(cabeza, dato):
    nuevo = Nodo(dato)
    nuevo.siguiente = cabeza
    return nuevo

def insertar(raiz, dato):
    if raiz is None:
        return NodoArbol(dato)
    if dato < raiz.dato:
        raiz.izq = insertar(raiz.izq, dato)
    else:
        raiz.der = insertar(raiz.der, dato)
    return raiz
